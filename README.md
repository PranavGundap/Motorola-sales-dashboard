# Motorola Sales Dashboard 📱

# Overview

An interactive Power BI dashboard built to analyze Motorola mobile sales performance.

# Features

- Sales Performance Analysis
- Monthly Quantity Trends
- Customer Ratings Analysis
- Payment Method Analysis
- Mobile Model Comparison
- City-wise Sales Analysis
- Interactive Month Filtering

# Tools Used

- Power BI
- Microsoft Excel
